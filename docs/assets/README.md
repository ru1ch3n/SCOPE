# Project-page assets

- `banner.svg`, `favicon.svg`: original vector branding. The banner's contours
  are decorative, not simulated fields or model outputs.
- `architecture.png`: rendering of the manuscript's existing SCOPE architecture
  figure. The field maps in it are schematic.
- `comparison.png`: rendering of the manuscript's existing grounding/readout
  figure. Values and labels have not been altered. Operator pairs have separate
  auxiliary protocols; see the caption and `../RESULTS.md`.
- `site.css`, `site.js`: standalone responsive presentation, keyboard-accessible
  quick-start tabs, and command copying. No analytics or authentication scripts.

GitHub Pages serves `docs/` from `main`. The scientific implementation and
configuration files are independent of the site.
